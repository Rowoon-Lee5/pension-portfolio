# 03. 50대 자영업자: 연금저축·노란우산공제·예금

## 문제의식
주변 자영업자 사례에서 출발했습니다. 50대 자영업자가 노후 대비로 매달 일정 금액을 따로 모은다면 연금저축(세액공제), 노란우산공제(소득공제, 폐업·노령 때 받음), 은행 예금 중 어디에 넣는 게 나을까요? 흔히 "연금저축은 세액공제가 있으니 무조건 이득"이라고 말하지만, 소득세를 거의 안 내는 사람에게는 돌려받을 세금이 없습니다. 중간에 꺼내면 오히려 세금을 냅니다. 이런 조건에서 세 상품이 실제로 어떻게 갈리는지 따져 봤습니다.

## 한 일
- **가상 인물**: 2026년에 만 57세인 자영업자. 월 10·30·50만 원(표는 30만 원), 연금저축은 주식 100%(자산 A) 또는 주식·채권 50:50(자산 B).
- **세금 그릇**: 그해 공제 전 소득세가 (가) 0원, (나) 약 50만 원, (다) 약 200만 원인 세 사람. 세액공제·소득공제는 이 그릇 안에서만 효과가 있습니다.
- **시점**: 3년째·5년째 전부 꺼냄, 62세, 70세(62세부터 해마다 나눠 꺼내 예금으로 옮긴 금액 포함). 노란우산은 그냥 해약, 폐업 수령(3·5년·62세), 노령 수령(70세)을 따로 봤습니다.
- **경로**: 과거 각 시작 연도(1992년~)부터의 실제 주식·예금 금리 경로(시작 연도 21~32개)와 부트스트랩 10,000경로.
- **규칙**: 연금저축 세액공제·기타소득세 16.5%·연금소득세(5.5%/4.4%, 1,500만 원 기준), 노란우산 소득공제·퇴직소득세, 건강보험료 시나리오, 기초연금 소득인정액(사람 A·B·C)을 법령 원문과 「2026년 기초연금 사업안내」에서 확인해 넣었습니다(`references/`). 퇴직소득세·기초연금 등 24개 항목은 손으로 계산한 값과 코드 값을 대조했습니다(`results/hand_checks.csv`).

## 결과: 상담표
주식 100%·월 30만 원·기준 셀. 칸의 숫자는 **앞쪽 상품이 예금보다 적었던 시작 연도 수 / 전체 시작 연도 수**입니다.

| 비교 | 3년째 꺼냄 | 5년째 꺼냄 | 62세 | 70세 |
|---|---|---|---|---|
| 연금저축 < 예금, 세금 0원 (가) | 14/32 비슷 | 12/30 비슷 | 10/29 대체로 유리 | 0/21 유리 |
| 연금저축 < 예금, 세금 0원 + 기초연금 경계 (사람 B) | | | | 중소도시 3/21 유리, 대도시 10/21 비슷 |
| 연금저축 < 예금, 세금 내는 사람 (다) | 14/32 비슷 | 11/30 비슷 | 3/29 유리 | 0/21 유리 |
| 노란우산 그냥 해약 < 예금 | 32/32 피하기 | 30/30 피하기 | | |
| 노란우산 폐업·노령 < 예금, 세금 0원 (가) | 14/32 비슷 | 13/30 비슷 | 13/29 비슷 | 10/21 비슷 |
| 노란우산 폐업·노령 < 예금, 세금 조금 (나) | 8/32 대체로 유리 | 7/30 대체로 유리 | 7/29 대체로 유리 | 7/21 대체로 유리 |
| 노란우산 폐업·노령 < 예금, 세금 많이 (다) | 0/32 유리 | 3/30 유리 | 2/29 유리 | 2/21 유리 |

- **판정 말(비슷·대체로 유리·유리·피하기)은 작성자가 정한 기준입니다.** 예금보다 적었던 해의 비율이 15% 미만이면 '유리', 15~35%면 '대체로 유리', 35%를 넘으면 '비슷', 모든 해에서 적었으면 '피하기'. 법이나 학계의 기준이 아닙니다.
- 노란우산은 3·5년·62세가 폐업 수령, 70세가 노령 수령입니다. 62세에는 노령 요건(가입 120회 + 60세)을 채우지 못합니다.
- '세금 0원 + 기초연금 경계'는 사람 B(국민연금 월 50만 원, 집 4억5천만 원, 소득인정액이 선정기준액의 87%)가 65~70세에 받는 기초연금까지 더한 비교입니다. 연금저축에서 받는 연금이 소득으로 잡혀 기초연금이 줄어들 수 있어서입니다. 중소도시·대도시는 기본재산액 지역 구분입니다. 이 칸은 사업안내 기준 해석(연금 전액을 소득으로, 수령 전 잔액은 금융재산으로)을 썼습니다.
- 표의 모든 숫자는 `results/N/grid_stats.csv`(기초연금 칸은 `results/N/bp_stats.csv`)에서 다시 셌습니다(`../check_numbers.py`).

## 말하면 안 되는 것
- "연금저축이 예금보다 낫다/못하다" — 세금 그릇, 꺼내는 시점, 기초연금 대상 여부에 따라 결론이 바뀝니다. 한 줄로 일반화할 수 없습니다.
- "노란우산에 가입하지 마라" — 해약하면 늘 예금보다 적었다는 것이지, 폐업·노령으로 받을 때나 세금을 내는 사람에게는 결과가 다릅니다.
- 판정 말을 개인 상담이나 권유로 쓰면 안 됩니다. 소득·재산·건강 사정이 이 가상 인물과 다르면 결과도 다릅니다.

## 한계
- 시작 연도가 21~32개지만 경로가 서로 겹쳐서, 서로 독립인 구간은 2~11개뿐입니다. 70세 비교는 독립 구간이 2개입니다. 그래서 차이의 신뢰구간은 내지 않았고, 칸이 많은데 다중비교 보정도 하지 않았습니다.
- 노란우산 이율은 2026년 값으로 고정했고, 예금만 과거 금리를 따릅니다. 노란우산 대 예금 결과는 사실상 과거 예금 금리 수준을 반영합니다.
- 세법·기초연금·건보료 규칙은 2026년 기준으로 고정했습니다. 건보료는 부과하지 않는 판(S_lo)이 기준이고, 몇몇 규칙(장기요양보험료, 근속연수공제 표 일부 등)은 원문을 확인하지 못해 결과 문서에 '미확인'으로 적었습니다.
- 70세 비교는 62세부터 인출하면서 70세까지 납입을 계속한다고 가정했습니다. 70세 차이의 대부분이 이 가정에서 나옵니다.
- 표시 기준(월 30만 원·주식 100%)과 요약 문장의 비교 규칙 일부는 결과를 본 뒤 정했습니다(결과 문서에 적음).
- 주식 수익률(코스피200 총수익)이 DataGuide·한국거래소 자료라 원자료 없이는 다시 돌릴 수 없습니다(`../DATA_SOURCES.md`).

**English summary.** For a hypothetical self-employed 57-year-old saving KRW 300k a month in equities, a tax-advantaged pension account fell short of a bank deposit in 40–44% of historical start years if cashed out after 3–5 years, but in none of 21 start years when held to 70; canceling the "Yellow Umbrella" mutual-aid plan always lost to the deposit. Tax, basic-pension and health-insurance rules were modeled from primary legal texts and checked against hand calculations; the verdict words in the table follow the author's own 15%/35% thresholds and are not advice.
