## 2. 새로 넣는 것

### N1. 퇴직소득세 (노란우산 폐업·노령 수령)
- 퇴직소득금액 = 공제금 − 소득공제 안 받은 납입 누계(조특법 §86의3③)
- 근속연수 = 납입월수 ÷ 12, 1년 미만 올림 1년(시행령 §80의3③)
- 세액 = 소득세법 §48·§55②: (금액 − 근속연수공제) × 12 ÷ 연수 → 환산급여공제 → 종합세율 → ÷ 12 × 연수, 지방세 10%
- 근속연수공제 표(소득세법 §48①1, 2023.1.1. 시행, law.go.kr 이미지 설명 글로 확인, 국세청 문서 대조 전): 5년 이하 100만원×연수 / 5~10년 500만원+200만원×(연수−5) / 10~20년 1,500만원+250만원×(연수−10) / 20년 초과 4,000만원+300만원×(연수−20)
- 환산급여공제: 800만 이하 전액 / ~7천만 800만+초과분 60% / ~1억 4,520만+55% / ~3억 6,170만+45% / 3억 초과 1억5,170만+35%
- 종합세율(§55①, 시행 2026.7.1.) 8구간: 1,400만 이하 6% / ~5,000만 15% / ~8,800만 24% / ~1.5억 35% / ~3억 38% / ~5억 40% / ~10억 42% / 10억 초과 45%. (지금 cand5.py는 하위 3구간만)
- 적용: 3·5년째 폐업 수령(wd36·wd60의 ny_close), 70세 노령 수령(p70의 ny_old). 62세는 노령 요건(60세+120회) 미충족이라 폐업 수령만 → **62세 폐업 칸을 새로 만든다**(p62의 ny_close: 폐업 적용이율로 적립, 퇴직소득세 뒤. 비교 쌍 연금저축 < 노란우산 폐업, 노란우산 폐업 < 예금 추가. 2026-11-06 회원 결정 8번). 동결판에 없던 칸이라 4절 대조에서는 뺀다.

### N2. 건강보험료 (지역가입자)
- 시나리오 S_hi(상한 시나리오 — 법령 문언상 포함으로 읽은 것, 공단 실제 부과 여부와 장기요양보험료율은 원문 미확인): 노란우산 해약 기타소득 100%, 연금저축 연금수령 연금소득 50%, 연금외수령 기타소득 100%에 7.19%. 보험료는 소득이 생긴 해의 다음다음 해 1~10월분과 다음 해 11~12월분에 반영(간단히: 소득 발생 이듬해부터 1년치 = 소득 × 반영률 × 7.19%로 근사, `ponytail:` 주석).

### N3. 기초연금 (65세~70세)
- 연금저축 수령 방식: 62세부터 해마다 잔액 ÷ (11 − 연차)를 꺼낸다(연금수령한도 × 1.2 이내, 시행령 §40의2③). 꺼낸 돈은 예금으로. 70세까지 납입은 그대로 계속한다(동결판과 비교하려고, 2026-11-06 회원 결정 2번).
- 인출 순서: 세액공제 안 받은 원금이 먼저 나온다 — 시행령 §40의3① 확인(`후보5_제도규칙_1차출처_20261027.md` 43행), 연금저축계좌설정약관(하나은행 약관 신구대비표) 기준(회원 결정 4번).
- 연금소득 1,500만 원(회원 결정 9번): 해마다 꺼낸 과세분이 그해 1,500만 원을 넘으면 종합과세(사람의 세금 그릇에서 §55 역산한 과세표준에 더해 8구간 세율, 지방세 포함)와 15%(+지방세 10%) 분리과세 중 작은 쪽. 넘지 않으면 5.5%(70세 미만)·4.4%. 70세 말 남은 잔액은 기존 D07 방식 그대로(1,500만 원 기준 적용 안 함). 소득세법 §14③9다 확인(스냅샷 `law_소득세법_59의3_57의2_129_21_14_20261010.md` 203행), §64의4 확인(제도규칙 73행). **r2에서 바뀜 → 6절 H3·M1·M2.**
- 65세부터 해마다 소득인정액 = 소득평가액 + 재산 소득환산액.
  - 소득평가액 = max(국민연금 + 연금저축 연금(K1에 따라) + 예금 이자 − 월 4만원, 0). **예금 이자를 넣는다**(2026-11-06 회원 결정 1번: 이전 설계서의 '예금·노란우산은 금융재산으로만'은 틀림).
  - 예금 이자 = (사람 고유 금융재산 + 시뮬레이션에서 생긴 예금 전부: 인출 예금·환급/절세 예금·예금 상품 잔액) × 그 달 세전 예금 금리(D05 모형). 금융재산 잔액은 그해 첫날 값으로 고정, 금리는 달마다.
  - 재산 소득환산액 = max(max(주택 − 기본재산액, 0) + max(금융재산 − 2천만원, 0) − 부채, 0)×4%÷12 — 각 괄호 0 하한(사업안내 인쇄 78쪽, 2026-11-07 수정, 7절).
- 기초연금(2026 고시 제2026-156호, 기초연금법 시행령 §10·§11):
  - 선정기준액 단독 247만원, 기준연금액 349,700원, 기본재산액 중소도시 8,500만원, 금융재산 공제 2,000만원, 환산율 연 4%.
  - 국민연금 연계감액: 국민연금 월액 ≤ 524,550원이면 전액. 524,550~699,400원이면 max(874,250 − 국민연금, §5 금액). 그 위는 A급여 자료가 필요 → 사람 3명은 이 구간에 두지 않는다.
  - 소득역전 방지: 소득인정액 + 기초연금 > 선정기준액이면 기초연금 = 247만 − 소득인정액, 최소 34,970원. 소득인정액 > 247만원이면 0원.
